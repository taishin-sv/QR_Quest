# ぼうけんカード メーカー

QRカードを使って、子どもが**ミッションをこなし、できたらもらったカードを読み込む**ことで進んでいくアプリです。
朝・夜のルーティン（といれ、はみがき、おきがえ…）や、おうちの遊び（縁日など）に使えます。

公開URL: https://taishin-sv.github.io/QR_Quest/

## どんなアプリか

1. 親が「ミッション」を並べたプリセットを用意する（最初から入っているテーマもある）
2. カード（連番のQRコードが印刷された紙）をPDFで書き出して印刷する
3. 子どもが**スタートカード**を読み込むと、最初のミッションが**音声で読み上げられる**
4. ミッションができたら、**親がカードを渡す**。子どもがそのカードを読み込むと、次のミッションが出る
5. 最後のカードを読み込むと、ゴールのメッセージと演出が出る

複数枚のカードを1つのミッションに割り当てられるので、きょうだい・友達で「3人で1枚ずつ持って、全員が読み込むと次へ進む」といった協力プレイもできます。

### 設計の考え方

- 子どもに画面を注視させない。端末は**据え置き**で、子どもが触るのは「カードを読み込む」と「次のミッションを聞く」ときだけ。
- ポイント・スコア・タイマーで煽る仕組みは入れない。演出は短く、モチベーション作りに必要な範囲にとどめる（健全なゲーミフィケーション）。
- 操作するのは5歳児、編集するのは親。プレイ画面はひらがな中心・大きなボタン。
- ミッションは、行動したあとに端末の前へ戻ってカードを読み込む流れが自然なものにする（例: 靴を履く、寝室へ移動する、はミッションにしない）。

## 主な機能

- **組み込みのテーマ別プリセット**（プリセット一覧はカテゴリーごとに表示）
  - あそび: きょうりゅうミッション
  - せいかつ: モーニングルーティン / ナイトルーティン
  - 自作・取り込んだものは「じぶんの ぼうけん」
- **ミッションの編集**: 並べ替え（▲▼）、行の追加・削除、1つのミッションで読み込むカード枚数（1〜5枚）、絵文字
- **きほんから えらぶ**: といれ・てあらい・はみがき・おきがえ・おふろなど、毎日の基本ミッションを選んで入れる
- **読み上げ**: 端末の日本語音声から聞き取りやすいものを自動選択。声と速さは変更可
- **効果音・演出**: スキャン時の効果音と振動（オフにできる）、ゴールの紙吹雪
- **カメラ**: 既定はインカメラ（🔄で切替）。据え置きでも使いやすい
- **メニューの収納**: 子どもが触って画面が変わらないよう、メニューを隠せる（再表示は左下の🔒を長押し）
- **タブレット（横向き）対応**: 左ナビ＋2カラムのレイアウト
- **共有**: プリセットをテキストで書き出し・取り込み（[`docs/presets/`](./docs/presets) に配布用の例）
- **印刷**: 縦長94×140mm（はがきサイズのラミネートポーチに収まる）、A4に4枚/ページ＋トンボのPDFを書き出し
- **オフライン動作**: 一度開けば、以降は通信なしで使える（PWA。ホーム画面に追加可能）

## 使い方の流れ

1. 「プリセット」タブで使うプリセットを選ぶ（「✏️ 編集」で内容を直せる。直したら「ほぞんする」）
2. 「いんさつ」タブで、そのプリセットに必要な枚数（例: `#1〜#5`）と**スタートカード**をPDFに書き出して印刷
3. 端末を据え置きにして「たんけん」タブを開く
4. スタートカードを読み込む → ミッションが読み上げられる → できたらカードを渡す → 読み込む…を繰り返す

カメラは `https://` または `localhost` でのみ動作します。

## 開発

```bash
npm install
npm run dev       # 開発サーバー (http://localhost:5173)
npm test          # ユニットテスト (vitest)
npm run build     # dist/ に本番ビルド（Service Worker含む）
npm run preview   # ビルド結果を確認 (http://localhost:4173)
npm run icons     # public/icon.svg から PWA アイコンPNGを再生成
```

### 構成

- `src/main.js` — UI（プリセット / 編集 / いんさつ / たんけん）
- `src/lib/`
  - `qr.js` — QRの中身（`ADVCARD:<番号>`）の符号化とパース。旧 `DINOQUEST:` のカードも読める
  - `stages.js` — カード番号とミッションの対応（ミッションごとの枚数から番号を割り振る）
  - `progress.js` — スキャン結果の判定と進行状況の管理
  - `presets.js` / `storage.js` — プリセットのlocalStorage保存、組み込みプリセットの反映
  - `builtin-presets.js` — 組み込みのテーマ別プリセット
  - `basic-missions.js` — 「きほんから えらぶ」の項目
  - `hints.js` — ミッションの並べ替え・追加・削除
  - `words.js` — 画面の文言
  - `speech.js` / `sfx.js` / `fx.js` — 読み上げ / 効果音 / 演出
  - `pdf.js` — カードのPDF書き出し（html2canvas + jsPDF。使うときに読み込む）
- `scripts/make-overlay.mjs` — 3枚重ねると絵が浮かび上がる透明フィルム用の印刷データを作る
- `docs/` — 仕様・経緯（`SPEC.md`）、配布用プリセット、重ねシートの印刷データ

### 組み込みプリセットの内容を直すとき

`src/lib/builtin-presets.js` で該当プリセットの文章を直し、**`rev` を1つ上げる**。手を入れていない端末では次回起動時に自動で新しい内容に置き換わり、編集済みのものは上書きしない（利用者が削除したものも復活しない）。置き換わったプリセットの進行状況は破棄される。

### データの保存

サーバー・DBはなく、すべて端末の `localStorage` に保存されます（プリセット、進行状況、読み上げ・カメラ・メニューの設定）。

## オフライン / PWA

依存ライブラリ・フォント(Zen Maru Gothic)はすべてnpmでバンドル済み。`vite-plugin-pwa` が全アセットをプリキャッシュ（約7MB）するので、**初回に一度開けば以降は完全オフラインで動作**し、ホーム画面に追加できます。更新は次回オンライン時に自動反映されます。

## デプロイ

### GitHub Pages（自動）

`main` にプッシュすると GitHub Actions（`.github/workflows/deploy.yml`）がテスト→ビルド→公開まで行います。
初回のみ、リポジトリの **Settings → Pages → Source を「GitHub Actions」** に設定してください。

### 自社サーバーなど

`npm run build` の `dist/` を静的ホスティングに置くだけです。`base: './'` の相対パスなのでサブパス配下でも動きます。HTTPS必須（カメラ・Service Worker）。
