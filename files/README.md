# ぼうけんカード メーカー

QRコードを使った、親子・友達同士で遊ぶ宝探し（脱出ゲーム風）アプリ。
詳しい仕様・設計判断の経緯は [`SPEC.md`](./SPEC.md) を参照。

## すぐ動かす

ビルド不要の単一HTMLファイルなので、そのままブラウザで開けば動く。

```bash
# ローカルで試す場合（カメラ機能を使うにはhttpsかlocalhost経由が必要）
python3 -m http.server 8000
# → http://localhost:8000/index.html をスマホ/タブレットのブラウザで開く
```

そのままファイルをダブルクリックして `file://` で開いても、編集・印刷（PDF書き出し）機能は動作する。カメラでのQRスキャン機能（「たんけん」タブ）のみ、ブラウザのセキュリティ制約上 `https://` または `http://localhost` 経由でのアクセスが必要。

## デプロイ

静的ファイル1枚なので、GitHub Pages / Netlify / Vercel / Cloudflare Pages などどこにでもそのまま置ける。ビルドコマンド不要、公開ディレクトリに `index.html` を置くだけ。

## 依存関係

すべて実行時にCDN経由で読み込み（npm管理下にはない）。詳細は `SPEC.md` の「外部依存」参照。オフライン対応やバンドルを行う場合はここから着手する。

## Claude Codeでの引き継ぎ手順の一例

1. このフォルダの中身を新規リポジトリの初期状態としてコミット
2. `SPEC.md` を読み込ませて設計意図を共有した上で、Claude Codeに追加開発を依頼する
3. 優先度が高い改善候補は `SPEC.md` の「10. 既知の制約・今後の検討課題」を参照（QRプレフィックスの改名、オフライン対応、PDF書き出し高速化など）
